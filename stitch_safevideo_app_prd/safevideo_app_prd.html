# Product Requirements Document: SafeVideo App ## Overview SafeVideo is a dual-app ecosystem designed to give parents complete control over the video content their children consume. Inspired by the ease of use of YouTube, it adds a critical layer of parental oversight, including content curation and time-based restrictions. ## Core Personas 1. **The Admin (Parent):** Needs a quick and efficient way to add videos, monitor usage, and set hard boundaries on screen time. 2. **The User (Child):** Needs a simple, engaging, and distraction-free environment to watch parent-approved content. ## Key Features - **Content Curation:** Admins can add videos via URL (YouTube, etc.). - **Parental Approval:** Only videos explicitly approved by the admin appear in the child's feed. - **Time Limits:** Admins can set a maximum daily viewing time. - **Schedule Controls:** Admins can define "active hours" when the app is accessible. - **Child-Friendly UI:** A simplified interface for the child app to prevent accidental navigation to unapproved areas. ## Proposed Screens - **Admin: Dashboard** - Overview of library and status. - **Admin: Add Video** - Form to input URLs and tags. - **Admin: Settings** - Time limits and schedule management. - **User: Home** - Curated video feed. - **User: Player** - Focused video viewing.
